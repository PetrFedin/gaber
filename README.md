# GABER — цифровая система проектирования и производства мебели

GABER объединяет параметрическое 3D-проектирование мягкой мебели, инженерную спецификацию (BOM), технологические нормативы и предварительную калькуляцию, версии предложений и локальный цикл взаимодействия клиента и фабрики.

**Текущее состояние:** инженерный прототип **v0.4.16 (Draft)** в ветке `feat/production-engineering-v04`. Это **не** работающая ERP/MES, не защищенная коммерческая платформа и не готовое к изготовлению изделие. `main` и production не менялись. **Production HOLD.**

## Что есть в коде
- Параметрические диваны, кресла и изголовья, WebGL и резервная SVG-визуализация.
- Детали каркаса, опоры, соединения, мягкие слои, связи 3D↔BOM и проверки комплектности.
- Демонстрационные калькуляции, ввод заводских данных, проверка происхождения ставок, сравнение ревизий.
- Сохранение/восстановление локальных проектов и версий расчета.
- Локальные заявки, предложения, корректировки, согласования, условные платежные записи, QC, отгрузка, претензии и принятие.
- Локальная операционная аналитика и серверные **контракты** разграничения прав и проверки документов.
- PostgreSQL-адаптер и SQL для технологического аудита — **не подключены к реальному серверу**.

## Локальный запуск
Требуются Node.js 22+ и npm; в CI предусмотрен Node 24.

```sh
npm ci
npm test
npm run build
npm run dev
```

Главный интерфейс использует hash-маршруты: `#studio`, `#projects`, `#factory`, `#operations`, `#costing`, `#technical`. Система хранит проекты и заказы в браузере, без независимой серверной авторизации. Нельзя вводить конфиденциальные данные.

## Ограничения выпуска
Сначала необходимы успешные GitHub Actions на точном SHA, реальные браузерные сценарии (375/768/1440 px), PostgreSQL + RLS, роли пользователей, подтверждение платежей и фабричных инженерных чертежей. До этого сохраняется HOLD.
