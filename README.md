# GABER — цифровое мебельное ателье

Рабочий прототип веб-приложения для выбора мягкой мебели, сохранения конфигураций и демонстрации взаимодействия клиента с фабрикой.

## Что работает в v0.1

- Каталог из трёх собственных цифровых семейств: диван Linea, кресло Forma, изголовье Tela.
- Параметрическая геометрия на Three.js: композиция, размеры, подлокотники, опоры, подушки и панели.
- Процедурные фактуры и цветовая палитра, физические материалы в WebGL.
- Автоматический упрощённый SVG-просмотр той же геометрии, если WebGL недоступен. Фактура и свет в этом режиме упрощены.
- Отмена/повтор, ракурсы, размеры, ссылка на конфигурацию.
- Сохранение вариантов в localStorage, сравнение, экспорт JSON.
- Связанные демонстрационные заявки и кабинет фабрики, состав затрат, скидка, маржа, экспорт CSV.
- Состояния заявки и история демонстрационных решений.
- Адаптивный интерфейс, самостоятельно размещаемые шрифты Golos Text и Manrope, иконки Lucide.

## Важная граница

Это **демонстрационная версия**, а не система для реальных производственных заказов. Материалы, нормы и цены иллюстративные. Библиотека не подтверждает инженерную пригодность изделий. Данные сохраняются только в этом браузере. Переключатель кабинетов не является аутентификацией или защитой доступа. Не вводите персональные и коммерчески чувствительные данные.

Сервер, PostgreSQL, вход и серверные роли пока не реализованы. Для рабочего запуска необходимо подключить и проверить реальные данные фабрики, защиту доступа и серверный расчёт.

## Запуск

Требуется Node.js 22+; CI использует Node.js 24.

```sh
npm ci
npm test
npm run dev
```

Сборка:

```sh
npm run build
```

Результат — `dist/`. Все маршруты используют hash, поэтому статическое размещение не требует серверных rewrite.

## Структура

- `src/domain.js` — каталог, проверка конфигурации, демонстрационная калькуляция, экспорт.
- `src/Scene.jsx` — параметрические модели, WebGL и SVG-просмотр.
- `src/App.jsx` — каталог, конструктор, проекты, материалы, кабинет фабрики.
- `src/storage.js` — локальное сохранение и ссылки.
- `tests/` — проверки инвариантов расчёта, ограничений, скидки и экспорта.
- `docs/technical-specification-v1.md` — полное исходное ТЗ, включая ещё не реализованные требования.
- `docs/architecture.md` — принятые решения и границы v0.1.
- `docs/roadmap.md` — следующая последовательность развития.

## Лицензии

Сторонние пакеты имеют собственные лицензии; они сохраняются в зависимостях и lock-файле. Three.js — MIT, React — MIT, Lucide — ISC, шрифты Fontsource — OFL согласно соответствующим пакетам. Собственная геометрия и процедурные фактуры созданы для проекта; они не являются моделями коллекций сторонних мебельных брендов. Публичная лицензия на код проекта не объявлена.

## Инженерный контур v0.4.2 — экспериментальная ветка

В `feat/production-engineering-v04` реализуются концептуальные инженерные спецификации и проверки конструкции: каркас, наполнители, 3D-инспекция, соединения, опоры и производственная прослеживаемость. Для шезлонга введены отдельные части несущей рамы и контроль соответствия внешнему габариту. Узлы каркаса, пружины/ремни, ламели и мягкие слои снабжены ссылками между сценой Three.js и техническим паспортом.

- [Техническая модель v0.4](docs/engineering-v0.4.md)
- [Проверка и ограничения v0.4.2](docs/verification-v0.4.2.md)
- [PR #2 — статус разработки](https://github.com/PetrFedin/gaber/pull/2)

**Не производственная версия:** артикулы, реальные нагрузки, допуски, материал, физически измеренные текстуры, маршруты фабрики и цены не подтверждены. Выпуск на производство программно заблокирован; смена визуальных параметров не является утверждением конструкторской документации. Облачные проверки, браузер/WebGL и мобильная визуализация требуют отдельного подтверждения. Рабочая ветка **не развернута вместо опубликованной версии**.
