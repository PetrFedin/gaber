## История (не источники действующих правил)

- [Исходное техническое задание](technical-specification-v1.md) включает требования, которые ещё не реализованы.
- [Архитектура первого прототипа](architecture.md) описывает v0.1.
- [Карта v0.4.16](project-map-v0.4.16.md) содержит отменённые шесть ролей.
- [Архивная матрица ролей](E2E-ROLE-ACCEPTANCE.md) не задаёт актуальные права.
- Датированные материалы verification-v0.4.* и audit-v0.4.* — исторические протоколы, а не подтверждение последнего HEAD.

При противоречиях действуют: текущие проверяемые исходники и тесты, затем контракт трёх ролей, затем статус с конкретным SHA. Факт коммита не равен успешной проверке.
