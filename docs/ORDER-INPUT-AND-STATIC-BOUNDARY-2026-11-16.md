## 1. Денежные поля и процент аванса

`src/serverOrderMoney.js` — единый парсер строковых полей серверного интерфейса `src/ServerOrders.jsx`.
Поле рублёвой суммы не округляется: дробные копейки (`2100,005`), экспоненты,
отрицательные числа, некорректное разделение тысяч и значения сверх
`1 000 000 000 000` коп. отклоняются до отправки команды в API.

| Поле | Граница ввода | Пример |
| --- | --- | --- |
| Цена клиенту и стоимость фабрики | строго больше 0 коп., максимум 2 знака | `2100,05` → `210005` коп. |
| Платёжная заявка и локальная запись оплаты | строго больше 0 коп. | `1050,03` → `105003` коп. |
| Комиссия, логистика, налоги, прочие затраты | 0 допустим; пустое значение → 0 | `0` → 0 коп. |
| Аванс в процентах | 0–100%, максимум 2 знака | `50,25` → 5025 базисных пунктов |

Некорректное поле подсвечивается предупреждением с названием; команда не отправляется.
Например, `50,999%` не округляется до `51,00%`. Допустимы `,` и `.` как десятичные
разделители, а также корректные группы тысяч с обычным или неразрывным пробелом.

**Область полномочий:** этот парсер — удобство и безопасность ввода на стороне
браузера. Это не финансовая авторизация. Серверный reducer / accessPolicy /
`partnerEconomics` продолжают независимо проверять целые копейки, роли,
версии, остаток, фабрику и стадии согласования. Записи оплаты по-прежнему не
являются подтверждением банка, а выпуск в производство запрещён.

## 2. Раздача Vite-ресурсов

В `server/staticFiles.js` добавлено разрешение реального пути с `realpath()` и
проверка, что файл действительно расположен внутри реального корневого
каталога сайта. Символические ссылки на файл **или промежуточный каталог**
вне корня возвращают 403. Ссылки на файлы внутри корня допускаются.
Обход через обратный слеш запрещён. Файл открывается по уже проверенному
каноническому пути.

**Ограничение:** каталог собранных ресурсов должен оставаться неизменяемым
для непривилегированных процессов во время обслуживания запросов.
Это исправление не заменяет безопасную конфигурацию файловой системы,
контейнера и инфраструктурный security review.
