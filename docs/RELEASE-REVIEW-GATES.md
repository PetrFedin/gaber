# GABER — независимая проверка и выпуск единой версии

**Статус: DRAFT PR #2 / PRODUCTION HOLD.** Цель — один SHA со
воспроизводимыми исходниками, достоверным протоколом заказа и
закрытыми обязательными тестами. Не переписывать историю, не открывать
новую конкурирующую ветку, не объединять в `main` до независимого ревью.

## Подтверждаемые автоматическими средствами ворота

| Gate | Доказательство успеха | Ограничения |
| --- | --- | --- |

| G1 — логика | Полный `tests/*.test.js`, в том числе клиент → партнёр → назначенная фабрика → ТЗ → согласование → заявка об оплате/запись → дефекты/приёмка | Изолированные репозитории не являются банковским settlement или действующим заводом |

## Обязательное независимое ревью

Ревьюер должен быть **не автором PR/изменений**. Назначение
автопроверки автора или собственная оценка этого документа НЕ считаются
независимым ревью. Ревьюер проверяет:

1. Ровно `client`, `factory`, `partner` в серверных DTO, данных и
   разрешённых действиях. `partner` — оператор GABER, видит комиссию,
   фабрика — только стоимость изготовления, клиент — свою цену.
2. Нельзя скрыть или подменить чужую организацию через URL, JWT claims,
   `app.tenant_id`, `factoryId`, `role`, `requestId` и прямой API.
   SQL GUC **не** является аутентификацией.
3. Нельзя опубликовать устаревшее R1 при `request_change` и новом S2;
   `factory.confirm_spec` без `partner.offer` не даёт нового предложения.
4. Нельзя назначить непроверенную фабрику, изменить immutable assignment,
   читать после отзыва допуска, открыть чужие диалоги, присвоить платежу
   банковскую подлинность или открыть реальное производство.
5. Нельзя включать историю собственного локального браузера в отчёт о
   фактической выручке/заказах клиента, либо выдавать демо BOM за заводской.
6. Ревьюер сверяет актуальные CI-ссылки **на том же SHA** и самостоятельно
   фиксирует замечания в GitHub review. После исправления требуется повтор
   всего набора проверок на новом SHA.

**Выпуск не может считаться готовым до одобрения независимого reviewer,
чистого восстановления и закрытия G4–G7.** Даже полный GREEN трёх
автоматических jobs означает воспроизводимый проверенный **демонстрационный
кандидат**, а не работающую коммерческую производственную платформу.
