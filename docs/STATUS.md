## Что нельзя выдавать за запуск

- Производство, КК, отгрузка, доставка и спор проходят **только через dev-симулятор** (`GABER_DEV_SIMULATE_EXTERNAL_AUTHORITY`); без него журнал отвечает `EXTERNAL_AUTHORITY_REQUIRED`. Банк не имитируется нигде.
- Старые кабинеты `#projects`, `#factory`, `#partner` остаются локальной симуляцией на localStorage.
- Все ставки, нормы, цены и материалы демонстрационные.

## Что пока НЕ подтверждено для коммерческой эксплуатации

- Реальный PSP settlement/refund, фабричное принятие CAD/BOM/норм, перевозчик и допуск в производство.
- Независимое код-ревью, тест на проникновение, восстановление из backup, мониторинг.
- Сброс пароля, подтверждение почты, резервные коды MFA, `trust proxy`.
- Зелёный GitHub Actions на последнем SHA (оплата не планируется; см. локальный шлюз).
- Публичный стенд: образ собран и запущен локально, на хостинге не развёрнут.
