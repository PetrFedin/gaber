## Какие дефекты устранены в ходе настоящего CI/E2E

1. Два устаревших Node-тестовых ожидания (234 теста, после исправления GREEN).
2. Node 24 global `navigator` с getter-only в DOM harness.
3. При корректировке клиентом заказа партнёр терял текст предыдущего ТЗ,
   и новая спецификация не отправлялась; восстановлено предзаполнение описания.
4. Поле label с предзаполненным `textarea` неправильно искалось DOM-тестом.
5. Денежная сумма R2 отображалась корректно с разделителем тысяч, но
   тест искал неверный локальный формат; проверяется точная цена в копейках.
6. Финансовый тест путал approval metadata и клиентский денежный ledger.
7. Настоящий браузер выявил: `#partner` не включён в whitelist
   `hashchange`; теперь работает переход из кабинета фабрики и сохранён
   legacy alias `#operations`.
8. Browser harness учитывает классическую полосу вертикальной прокрутки
   15 px при сравнении outerViewport и `documentElement.clientWidth`.

## Границы доказанной работоспособности

Эта версия — **проверенный демонстрационный/интеграционный кандидат**:
- Клиент, фабрика и партнёр работают с локальным журналом браузера.
  Навигация между кабинетами не является серверной аутентификацией.
- Серверные журналы, admission, tenant policies, SQL адаптеры и реальные
  PostgreSQL-модули есть в коде, но **полноценное подключение UI → HTTP API →
  независимые JWT/MFA сессии → PostgreSQL ещё не доказано реальным E2E**.
- Банковское подтверждение, платёжный шлюз, возвраты и release комиссии —
  не подключены к настоящему PSP. Тестовые записи оплаты не реальные деньги.
- Технические CAD/BOM, заводские нормы/лекала, согласование производства,
  измеренные материалы, реальный ОТК, доставка и претензии с документами
  не подтверждены фабрикой.
- Полноценные 3D/WebGL визуальные показатели (FPS, кадры, GPU/среды),
  скриншоты для ручного UI approval и mobile touch QA требуют отдельной
  независимой приёмки. Browser smoke лишь проверяет DOM/маршрут/ширину.
- Нет независимого ревью PR от отдельного человека. Нет чистого checkout
  + банк/DB restore gate, нет подписи к выпуску. `main` не менялась.
