# Архитектура GABER v0.1

## Принятые решения

React 19 — интерфейс; Vite 7 — сборка; Three.js 0.186 — геометрия, камера и основной WebGL-рендер; Lucide — SVG-иконки; Fontsource — локально размещаемые шрифты. Точные разрешённые версии находятся в package-lock.json.

Код первого прототипа — JavaScript/JSX ES modules. TypeScript из целевой архитектуры ТЗ ещё не внедрён; следующая миграция должна закрепить схемы конфигурации и контрактов. Использование коммерческого 3D SDK в v0.1 не требуется и не подключено.

## Поток данных

Действие пользователя -> конфигурация -> проверка -> демонстрационный BOM/калькуляция -> изображение и сводка -> локальный снимок варианта -> демо-заявка -> дело проекта -> демонстрационное предложение.

Сохранённая конфигурация и её estimate копируются, чтобы последующая настройка нового предмета не меняла старый вариант. При подготовке предложения скидка хранится отдельным quote, нормативная себестоимость не переписывается. Все данные доступны владельцу браузера: это не механизм защиты маржи.

## Визуализация

Детали строятся отдельно из RoundedBoxGeometry. На материал назначается цвет и процедурная bump-фактура; ножки имеют отдельный материал. Параметры высоты изменяют спинку, ширины — размеры и положение модулей. Это цифровые формы для проверки интерфейса, не инженерный CAD.

При отсутствии WebGL применяется SVGRenderer из Three.js с той же структурой модели и упрощённой геометрией. В этом режиме нет полноценного PBR и фотографической точности. Рендер выполняется при изменениях, автоматическое вращение выключено. Кнопки камеры и выбор частей продолжают работать.

## Целевая серверная граница

До реальных заказов необходимо реализовать серверную проверку конфигурации, расчёт по утверждённым нормам, PostgreSQL, аккаунты, объектные права, неизменяемые версии предложения и идемпотентное создание заявки. Публичный клиент не должен получать закупочные цены и нормы труда.

Первый серверный слой реализован на ветке `gaber-backend` (Fastify, PostgreSQL, вход, роли, расчёт на сервере): см. [server.md](server.md). Он остаётся прототипом на демонстрационных данных: организации, КП/PDF, уведомления и продакшен-развёртывание не сделаны. Облачные аккаунты и платные услуги не создавались.
