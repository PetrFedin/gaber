# GABER / инженерный цифровой двойник v0.3 — концепт

Дата: 17 октября 2026. Ветка: `feat/engineering-digital-twin-v03`.

## Подтверждённый объём реализации

- `src/engineering.js`: детерминированный инженерный объект по конфигурации (габарит, количество модулей, посадка, раскрой каркаса, слои, поддержка, обивка, фурнитура, контрольные ворота).
- `src/EngineeringAssembly.js`: инспекционная 3D-геометрия бруса, фанеры, пружин-змеек или эластичных ремней, многослойного ППУ или Pocket Spring.
- `src/Scene.jsx`: режим `exploded` переключён с иллюстративного разнесения мягких внешних форм на срез внутренних узлов.
- `src/ConfiguratorPanel.jsx`: регулировка высоты сиденья (40–52 см), глубины посадки (45–70 см), угла наклона спинки (4–20° от вертикали), типа поддержки и сердечника.
- `src/TechnicalPage.jsx`: ведомость размеров деталей, слои наполнения, фурнитура, автоматические и неподтверждённые проверки, экспорт отдельного JSON и CSV.
- `tests/engineering.test.js`: автоматические инварианты пяти семейств, влияния размеров на детали, несовместимости Pocket Spring с креслом-кроватью, старых проектов и блокировки производства.

## Проектные параметры (не стандарты и не нормы фабрики)

| Узел | Предположение |
| --- | --- |
| Брус царг | Хвойная древесина 40×60 мм |
| Фанера угловых косынок/боковин | Берёзовая 18 мм |
| Фанера панелей спинки/изголовья | Берёзовая 12 мм |
| Сиденье ППУ, balanced | HR35 100 мм + HR30 30 мм + настил 10 мм |
| Сиденье ППУ, soft | HR35 85 мм + HR30 45 мм + настил 10 мм |
| Сиденье ППУ, firm | HR40 110 мм + HR30 20 мм + настил 10 мм |
| Вариант Pocket Spring | кассета 80 мм + HR35 50 мм + настил 10 мм |
| Спинка | ППУ HR25 50 мм + настил 10 мм |
| Изголовье | ППУ HR25 40 мм + настил 10 мм |
| Проектный шаг ремней/пружин | 85/90 мм соответственно, не утверждённый монтажный шаг |
| Припуск шва | 12 мм, уточнить по конкретному чехлу/ткани |

Обозначения HR35, HR30, HR25 здесь — названия проектных классов и номинальные плотности в кг/м³, **не гарантия химического типа пены и не измеренные характеристики**. В паспорте поставщика отдельно подтвердить плотность, напряжение сжатия (IFD/CLD), остаточную деформацию, долговечность и соответствие назначению. Условная цифровая ткань не имеет реального артикула, результаты тестов Martindale и пожарной классификации не указаны.

## Отдельные проверки готовности

* Автоматически: схема конфигурации, положительные размеры деталей, приближённый минимум ширины модуля, посадка в габарит, толщина/высота базы.
* Требуют технологии: точные стыки, вкладыши, столярные соединения, нагрузка и устойчивость, механизм трансформации, реальные крепления, геометрия шва, деформации ткани, раскрой, допуски, испытания безопасности, электрооснащение.
* Статус `productionRelease.allowed=false` в **каждом** сформированном инженерном объекте; штатного пути перевода в production в демо нет.

## Источники и границы проверки

Исходные параметры конструктора и демонстрационная логика: `src/domain.js`, `src/Scene.jsx`, `docs/expansion-v0.2.md`.

Спецификации API визуализации: https://threejs.org/docs/#api/en/core/Object3D , https://threejs.org/docs/#api/en/geometries/TubeGeometry

Измеренные мебельные свойства, соответствие ГОСТ/EN/ISO, надёжность и эргономическая пригодность не подтверждены испытаниями. Настоящая технологическая документация и нормы производства требуют информации реальной фабрики и согласования инженера-конструктора.

## Проверки выпуска

`npm ci && npm test && npm run build` в GitHub Actions. Проверка на реальных GPU/mobile отдельно. Если workflow не дал зелёный результат, запрещено называть сборку прошедшей тестирование.
