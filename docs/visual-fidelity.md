# Качество изображения и доверие клиента

Цель: клиент перед заказом видит изделие так, как оно будет выглядеть дома, и знает, что на картинке точно, а что приблизительно.

Код: `src/fidelity.js` (геометрия, фактуры, свет, просадка, человек), `src/Scene.jsx` (рендер), `src/QualityDock.jsx` (панель «Проверка»). Размеры, цены и конфигурация изделия этим слоем не меняются.

## Что сделано

| Что                       | Как                                                                                                                                                                                                                                                                                                       |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Объёмные подушки          | Собственная сетка `cushionGeometry`: плотная в середине грани и у скруглений. Середина набухает (`shapeCushion`), края и шов остаются на месте, нормали наклоняются по тому же рельефу. `RoundedBoxGeometry` для этого не годится: его плоская грань — один четырёхугольник.                              |
| Кант                      | Трубка по контуру шва вместо линии (в упрощённом SVG-режиме остаётся линия).                                                                                                                                                                                                                              |
| Ткань в реальном масштабе | UV считаются в метрах, повтор рисунка задан в сантиметрах для каждого типа. Рельеф и лёгкое затемнение борозд: шесть процедурных фактур (рогожка, букле, велюр, микровельвет, кожа, фетр).                                                                                                                |
| Свет                      | День, вечер, холодный: оттенок меняется от освещения, клиент видит это сам.                                                                                                                                                                                                                               |
| Затенение                 | Режим «Высокое»: GTAO (затенение в складках и у пола), MSAA 4×, тени 2048. «Стандарт» для слабых устройств и телефонов выбирается автоматически.                                                                                                                                                          |
| Масштаб                   | Нейтральная фигура 175 см стоит рядом или сидит на диване.                                                                                                                                                                                                                                                |
| Посадка                   | «Присесть»: подушка проседает по гауссиане до 7,5 см, фигура садится. Иллюстрация, не расчёт жёсткости.                                                                                                                                                                                                   |
| Ракурсы                   | Спереди, сбоку, сзади, сверху и «Ткань вблизи». Панель отмечает, что клиент уже посмотрел. Ничего не блокирует и не торопит.                                                                                                                                                                              |
| Фото                      | 2400 × 1600 PNG: 24 прохода с субпиксельным сдвигом и мягким источником света. Кадр подбирается под габариты изделия.                                                                                                                                                                                     |
| AR дома                   | Кнопка «Дома у себя (AR)»: GLB только мебели, в метрах (без комнаты и человека) открывается в `<model-viewer>` с фиксированным масштабом 1:1. Android Chrome (WebXR) и iPhone Safari (Quick Look). Библиотека грузится только по нажатию. Можно скачать GLB. На компьютере показывается обычный просмотр. |
| Честность                 | В панели есть раздел «Что на картинке точно, а что нет».                                                                                                                                                                                                                                                  |

## Чего здесь нет (не обещать клиенту)

- Это растеризация, а не трассировка лучей: отражения и переотражения света не считаются.
- Фактуры процедурные, не сканы реальных тканей. Оттенок на экране зависит от калибровки монитора.
- Просадка подушки не зависит от реального наполнения: фабрика его не задавала.
- Фигура человека схематична и нужна только для масштаба.

## Следующий шаг по качеству

1. Сканы тканей фабрики (albedo, normal, roughness) с физическим масштабом плетения. Подключаются в `fabricMaps`.
2. Модели от 3D-художника в GLB с именованными узлами; процедурные подушки остаются запасным вариантом.
3. Образец реального изделия: рендер и фото рядом, сверка оттенка (ΔE), метрика точности для клиента и инвестора.
4. Проверить AR на реальных iPhone и Android (в разработке проверен только просмотр на компьютере) и добавить WebXR VR для шоурума.
5. Трассировка лучей в браузере для режима «Фото» (`three-gpu-pathtracer`) после появления настоящих моделей.

## Зависимость model-viewer

`@google/model-viewer` объявляет peer `three@^0.183`, а проект на 0.186. Подключается готовая сборка `dist/model-viewer.min.js`, в которой своя копия three, поэтому конфликта в работе нет. Чтобы `npm ci` не падал на peer-проверке, в репозитории лежит `.npmrc` с `legacy-peer-deps=true`. Когда выйдет версия с поддержкой новой three, `.npmrc` можно удалить.
